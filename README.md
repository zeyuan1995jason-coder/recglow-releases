# ScreenCraft 下载 / Downloads

macOS 录屏与剪辑工具。在 [Releases](../../releases/latest) 下载最新的 `.dmg`，打开后把 ScreenCraft 拖进「应用程序」即可。已安装的用户会在 App 里自动收到更新。

A screen recorder and editor for macOS. Download the latest `.dmg` from [Releases](../../releases/latest), open it and drag ScreenCraft into Applications. Installed copies update themselves.

需要 macOS 15 或更高版本 · Requires macOS 15 or later.

本仓库只存放安装包和更新清单（`appcast.xml`），不包含源代码。
This repository only hosts installers and the update feed (`appcast.xml`); it contains no source code.
